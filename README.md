# Weather App

A clean, fast, and responsive frontend weather application that provides real-time atmospheric data, temperature updates, and weather forecasts using external weather APIs.

---

## Features

- **Live Weather Updates:** Fetches current temperature, humidity, wind speed, and weather conditions.
- **City Search:** Easily search weather details for any city worldwide.
- **Responsive Design:** Optimized for both desktop and mobile screens.
- **Dynamic UI:** Dynamic icons and indicators reflecting live weather conditions.

---

## Built With

- **HTML5:** Semantic page structure
- **CSS3:** Responsive layout, modern styling, and animations
- **JavaScript (ES6+):** Dynamic DOM manipulation and asynchronous API fetching
- **Weather API:** [OpenWeatherMap](https://openweathermap.org/) (or your chosen weather API provider)

---

## Getting Started

### Prerequisites

You only need a modern web browser (Chrome, Firefox, Edge, Safari).
